# Quickey

The two-second file converter for Windows. Drag a file, tap a key, drop it on a format.

**[Download Quickey for Windows](https://github.com/namastetechy-cell/quickey-releases/releases/latest/download/Quickey-win-Setup.exe)** · [Website](https://namastetechy-cell.github.io/quickey-releases/) · [All versions](https://github.com/namastetechy-cell/quickey-releases/releases)

Works on Windows 10 (version 2004 or later) and Windows 11, 64-bit. Questions or problems? [Open an issue](https://github.com/namastetechy-cell/quickey-releases/issues).
